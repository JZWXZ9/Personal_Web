auto_vaulting

Minecraft 试炼宝库自动开箱脚本

查看 GitHub ↗

01 / CONTEXT

从游戏机制里，
找到一个自动化问题。

试炼宝库允许稀缺物品再生，但同一名玩家只能开启一次。项目利用 Carpet Mod 的假人功能，结合服务器对已开启玩家记录的限制，尝试实现批量、稳定的自动开箱流程。

02 / WHAT IT DOES

四个连续动作，
一套可校验的循环。

01生成假人在指定坐标按配置创建带编号的假人。
02执行右键通过聊天栏自动发送指令，完成开箱操作。
03退出假人操作完成后自动清理当前假人。
04日志验证监听 Minecraft 聊天日志，确认召唤和退出是否成功。

03 / CONFIGURATION

把变化留给配置，
把流程固定下来。

项目通过 config.py 集中管理日志路径、生成坐标、朝向、假人名称、循环次数和时间间隔等参数，让脚本能够适配不同的本地游戏环境。

config.py位置 · 朝向 · 前缀 · 轮次 · 间隔

04 / RELIABILITY

不是只执行，
还要确认执行成功。

脚本通过装饰器封装“发送指令—读取日志—判断反馈”的过程。如果没有在日志中确认假人已经进入或退出，流程会等待后重试；对于退出后的操作，也会再次发送右键指令。这让自动化流程不只依赖固定等待时间，而是有了来自游戏日志的状态反馈。
